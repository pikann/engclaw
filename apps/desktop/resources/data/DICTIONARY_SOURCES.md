# Dictionary data sources and attribution

`dictionary.sqlite` is a read-only database built from the open sources below. Its version and
SHA-256 checksum are in `dictionary.manifest.json`. It is regenerated by
`scripts/data/build-dictionary.ts` from intermediate datasets kept in `.cache/data/` (not committed).

| Data                                                          | Source                                                                                                                                                             | License                   |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------- |
| Definitions, examples, word list                              | [Open English WordNet](https://en-word.net/) 2024, derived from Princeton WordNet                                                                                  | CC BY 4.0                 |
| Pronunciations (IPA)                                          | [CMUdict](https://github.com/cmusphinx/cmudict), converted from ARPAbet                                                                                            | BSD-2-Clause              |
| Origin chains, PIE roots, first-use dates                     | [Wiktionary](https://en.wiktionary.org/) contributors, extracted by [Wiktextract](https://github.com/tatuylonen/wiktextract) via [kaikki.org](https://kaikki.org/) | CC BY-SA 4.0              |
| Root families (all words sharing a root's Latin/Greek source) | Wiktionary English, Latin and Ancient Greek entries via `scripts/data/build-root-families.ts` (kaikki.org dumps)                                                   | CC BY-SA 4.0              |
| Roots, meanings, origin languages, example words              | [learnthat.org roots](https://www.learnthat.org/pages/view/roots.html) (facts only)                                                                                | Attribution and link-back |

## Share-alike

The `etymology` table and `word-etymology.json` contain Wiktionary-derived data licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Any redistribution or adaptation of
that data must keep this license and attribution. etymonline text is not included; each word only
carries a link-back URL.
