# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report privately using GitHub's [private vulnerability reporting](https://github.com/pikann/engclaw/security/advisories/new) for this repository.

Include the affected version, your OS, steps to reproduce, and the impact. You can expect an acknowledgement within a few days. We will coordinate a fix and disclosure timeline with you.

## Scope

In scope: the Electron app (main process, preload, IPC, renderer), model download and verification, and the build/release pipeline. Out of scope: vulnerabilities in third-party services (YouTube, Hugging Face) or in upstream dependencies without a demonstrated impact on Engclaw.
